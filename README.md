# Python 切片（Slicing）

純 HTML、CSS、JavaScript 的 Python 切片互動教具。學員直接開啟網址即可使用，不需要帳號、Python 或安裝套件。

## 使用方式

- 上方為 2:1 的切片觀察台與操作區，下方是獨立全寬的寫法比較表。
- 文字序列支援中文、英文、數字、空白和 emoji，前後空白會保留，最多 500 個 Unicode code points。
- 輸入 `text[-2::-1]`、`[-2:]` 或 `-2:`，可同步 start、stop、step。也可以反過來修改參數。
- 支援單一索引、一個冒號、兩個冒號。留空代表省略，step 預設為 1。
- 播放、上一步、下一步與重播起點可觀察取值順序。
- 五個教學情境包含 28 個範例：易混淆寫法、冒號與步長、頭尾截取、反向與邊界、數字三角形。
- 點選比較表的寫法可套用到觀察台，參數、結果和解釋均依目前字串更新。

`text = "1234567"`：

| 寫法 | 結果 | 意義 |
| --- | --- | --- |
| `text[-2]` | `"6"` | 單一索引 |
| `text[-2:]` | `"67"` | 從倒數第二個向右取到最後 |
| `text[-2:-1]` | `"6"` | 不包含 stop |
| `text[-2::-1]` | `"654321"` | 從倒數第二個向左取值 |
| `text[-1:-2]` | `""` | 預設向右，範圍內無字元 |
| `text[-1:-2:-1]` | `"7"` | 明確向左 |

負索引只決定位置，step 才決定方向。負步長時省略 stop 與明確指定 -1 不同。
單一索引超界顯示 IndexError，切片超界會裁切，step = 0 顯示錯誤。錯誤時仍保留已解析的參數。
emoji 按 Unicode code point 計算；組合 emoji 可能占多格，這與 Python 字串相同。

## 本地預覽

下載此儲存庫並解壓縮後，直接開啟 `index.html`。不需要安裝套件或啟動後端。

## 網站檔案

- `index.html`：主畫面。
- `style.css`：版面與響應式樣式。
- `app.js`：輸入同步、比較表與動畫。
- `slicing.js`：使用 BigInt 模擬 Python 索引與切片。
- `lessons.js`：5 個情境、28 個教學範例。

所有輸入與計算都在瀏覽器記憶體中完成，不需要登入，不儲存或上傳輸入內容，重新整理即回到預設值。
